How launching works

  1. One window at a time. The app opens the first account, waits until its window is up, then opens the next.
  2. Multi-instance is automatic. Each new window is unlocked so the next one doesn't close it.
  3. FPS per account. Set "Opens at" on the Accounts page — e.g. 30 for the account that moves, 5 for the one that sits still.
  4. No browser needed. Your saved logins are used to join directly, through Bloxstrap if you have it.
  5. Too many launches in a row can make Roblox refuse for a minute. Just wait and try again.

  1. Make a channel in your Discord server. To keep it private: Edit Channel → Permissions → Private Channel.
